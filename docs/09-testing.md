# 09 — 测试

## 1. 测试金字塔

| 层级 | 范围 | 运行环境 | 速度 |
| --- | --- | --- | --- |
| 单元测试 | 协议编解码、页面组合、遍历展开、校验器、模板、布局数学 | JVM | 秒级 |
| 属性/模糊测试 | 随机解码、组合循环、遍历上限 | JVM | 秒级到分钟级 |
| 黄金测试 | 协议 1.1 逐字节夹具 | JVM | 毫秒级 |
| 集成测试 | 真实 Paper + 真实客户端，六类面板场景 | 本地/自托管 runner | 分钟级 |
| 手动矩阵 | 视觉、输入、面板互操作 | 人工 | 每个版本 |

渲染正确性由手动矩阵和截图对比覆盖；不需要为 Minecraft 渲染写断言 mock 的单元测试。

## 2. 协议测试

### 2.1 往返

每种报文构造→编码→解码→断言相等。jqwik 覆盖边界：`0`、`1`、`-1`、`Integer.MIN_VALUE`、
最大字符串、空列表、最大深度 map。

### 2.2 黄金向量

`cloudcore-protocol/src/test/resources/vectors/1.1/<name>.hex`：

```
# name: UI_OPEN_container
# proto: 1.1
43 43 01 00 10 ...
```

向量变化意味着协议变化，必须做版本升级决策。特别覆盖：

- `UI_OPEN` 六种 surface × 四种 bindMode。
- `UI_READY` 五种 state。
- `ELEMENT_UPDATE` 每种属性。
- `DIAGNOSTIC` 各 severity、超长 detail、去重键。
- 分片、压缩、空 body。

### 2.3 模糊测试

- 100 万随机字节数组走完整解码；无异常逃逸、无按声明长度分配、单输入耗时有限。
- 结构化模糊：合法帧头 + 随机 body。
- 解压炸弹：1 MiB 帧声称 1 GiB，必须在上限处拒绝。
- 分片模糊：重复、缺失、乱序、255 片、count 0。
- 特性位模糊：未知特性位不得导致崩溃。

### 2.4 限额测试

`Limits` 每项都有"刚好"和"超过一"两个测试。

## 3. 页面组合测试

- 单文件页面与等价多片段页面编译结果一致（逐字节 JSON）。
- 片段顺序影响元素顺序；重复元素 id 报错。
- 状态、主题、字体、动作的合并优先级符合 `12-page-composition.md`。
- 循环 include 被检测；深度 > 8、文件数 > 64 被拒绝。
- 片段修改只让依赖页面提升修订号。
- 缺失片段给出文件名与行号。
- 路径不能逃出 `pages/` 目录（`..`、绝对路径、符号链接）。

## 4. 遍历测试

- 64 项列表展开为 64 个实例，实例 id 稳定且唯一。
- `source` 不是列表时运行时报错，不崩溃。
- 列表增删触发修订号提升与完整文档下发。
- 单 repeat 超过 256、整文档超过 512 时拒绝并记录。
- 嵌套 3 层被校验器拒绝。
- 遍历项中的模板变量 `${item.field}`、`${i}` 正确求值。
- 点击第 3 项时 `actionId` 对应到正确的实例。

## 5. 文档与校验器测试

- 每种元素类型至少一个合法示例。
- 每条校验规则至少一个失败示例，产生预期错误码。
- 模板：优先级、括号、短路、未知根、除零、溢出、字符串比较、未闭合字面量。
- 别名归一化：同一对象同时出现别名和规范键是错误。
- 面板与文档匹配：`surface: hud` 带槽位被拒绝；`surface: container` 缺 `container` 被拒绝。
- 字体：未知 provider、未知回退链、非法标识符被拒绝。
- 模糊 YAML：随机键值产生校验错误，不抛堆栈。
- 下发文档断言：不含 `state`、动作体、`repeat`、`includes`、原始 URL 或命令。
- 同主版本未知字段被忽略；未知元素类型/枚举值被拒绝。
- 主题令牌在客户端按 `THEME_SET` 正确解析，换主题不重发文档。
- 同一组失败文档在服务端校验器与客户端解析器上得到一致结论（错误码可映射）。

## 6. 服务端集成

测试装置：

- `run-paper` 启动 Paper 1.21.11，加载插件和测试世界。
- `/cloudcore selftest` 运行场景并写 JSON。
- 无头测试客户端（见第 7 节）或控制台驱动。

场景：

1. 加入 → `HELLO` → `HELLO_ACK` → 能力位与面板列表正确。
2. 容器：预绑定 → `UI_READY` → 界面替换 → 点击。
3. 独立页面：`bindMode=NONE` 开屏。
4. 玩家背包：加入后收到持久文档；打开背包应用皮肤。
5. HUD：三个层各注册一次；更新只发差异。
6. Tooltip：样式文档下发；滚动上报默认关闭。
7. Boss 血条：哨兵标题绑定；移除血条后会话关闭。
8. 旧界面：第三方箱子被换皮，点击仍到达插件。
9. 取消 `InventoryOpenEvent` 不留下悬空会话。
10. `reload` 后依赖页面修订号提升，客户端保持可用。
11. 权限撤销后对应面板关闭。
12. 玩家退出：所有会话移除，无泄漏。
13. URL 贴图：默认客户端直连并缓存；服务端不发送图片字节；内网/回环/超限 URL 被拒绝。
14. 代理模式：客户端请求后服务端按配置下发；`auto` 在直连失败后回退。
15. GIF：直连模式客户端解码、代理模式服务端解码；超帧数/超尺寸被拒绝。
15. 占位符：`interval` 只推送变化值；慢扩展被预算推迟；异步白名单外仍同步。
16. 下发文档不含动作体/命令/state；客户端只能拿到 actionId。
17. 主题令牌切换只发 `THEME_SET`，不重发文档。
18. 服务端页面编译失败时发送 `DIAGNOSTIC`，客户端日志出现 `CC-DOC-*` 和相对路径。
19. 服务端屏蔽 `diagnostics.send-client-details` 后不再下发 detail，但仍写服务端日志。

## 7. 客户端测试模式

系统属性激活（`-Dcloudcore.test.scenario=...`）：

- 自动连接本地服务端；
- 可切换 `renderer=nanovg|native` 跑同一套场景；
- 脚本化打开/关闭六类面板；
- 模拟点击、输入、滚轮；
- 断言界面类型、会话状态、滚动偏移、Boss 绑定数、报文计数；
- 写出 `build/test-results/client/<scenario>.json`；
- 失败非零退出。

需要显示器：本地 Windows runner 或 Linux + Xvfb + 软件 GL。测试模式不打进发布 jar。

## 5.1 日志与诊断

- 每个 `CC-*` 前缀至少一个触发用例，断言日志含错误码、uiId/revision/elementId/字段路径。
- 服务端 `DIAGNOSTIC`：severity/code/scope/message/detail 写入客户端日志；detail 截断、去重、限流。
- 脱敏：输入内容、令牌、URL query、IP、绝对路径不出现在日志和诊断包。
- 日志注入：带 `\n`、`\r`、Unicode 方向控制符的错误文本被清洗。
- 轮转：超过大小生成新文件，旧文件保留。
- 限流：同一错误 1 秒 100 次只完整输出一次，后续计数。
- 诊断包：`F10`/`dump` 生成 zip，包含日志、配置、系统信息、最近报文头，可解压且无敏感数据。
- 异步：日志队列满时丢弃并计数，不阻塞渲染线程。

## 8. 手动矩阵

### 8.1 环境

| 维度 | 取值 |
| --- | --- |
| GUI 缩放 | 1、2、3、4、自动 |
| 分辨率 | 1280×720、1920×1080、2560×1440、3840×2160 |
| 窗口模式 | 窗口、全屏 |
| 网络 | 局域网、模拟 80 ms |
| 字体 | NanoVG TTF、资源包 TTF、原生 `Font` |

### 8.1.1 渲染后端

- [ ] Windows/Linux/macOS：NanoVG 初始化、FBO 创建、字体加载、合成。
- [ ] GUI 缩放 1–4、窗口/全屏、分辨率变化后 FBO 重建正确。
- [ ] 半透明面板/文字无黑边、白边或色差（预乘 alpha）。
- [ ] NanoVG 背景 → 原版物品 → NanoVG 前景的分层顺序正确。
- [ ] 禁用原生库/强制 FBO 失败时回退 `NativeBackend`。
- [ ] Sodium/Iris 开/关下无异常，必要时可配置回退。
- [ ] FBO 尺寸不随鼠标移动逐帧变化，窗口变化才重建。
- [ ] NanoVG 文本与 EditBox 文本在视觉上可接受，或使用本地 CloudCore 目录里的匹配 MC 字体。

### 8.2 通用

- [ ] 六类面板能独立启用/禁用；禁用后完全恢复原版。
- [ ] 面板之间互不影响（HUD + 背包 + Tooltip + Boss 同时开）。
- [ ] 窗口尺寸变化后重新布局。
- [ ] GUI 缩放变化后重新布局。
- [ ] 断线重连无残留界面。
- [ ] 原版客户端不受影响。
- [ ] 有模组无插件无通道流量。

### 8.3 容器面板

- [ ] 槽位点击、Shift、拖拽、数字键、双击、副手。
- [ ] 未声明槽位无响应。
- [ ] `managed` / `readonly` / `passthrough` 行为。
- [ ] 第三方箱子换皮，点击逻辑不变。

### 8.4 玩家背包

- [ ] 打开 `E` 应用皮肤；再次打开保持一致。
- [ ] 合成、护甲、主物品栏、快捷栏、副手槽位正确。
- [ ] 配方书隐藏；关闭皮肤后配方书恢复。
- [ ] 玩家模型与效果图标开关。
- [ ] 创造模式背包不受影响。

### 8.5 HUD

- [ ] 三层 HUD 叠加顺序正确。
- [ ] 隐藏时无绘制。
- [ ] 状态更新无闪烁。

### 8.6 Tooltip

- [ ] 短提示不滚动、不消费滚轮。
- [ ] 长提示出现滚动条，滚轮可滚动。
- [ ] 滚轮滚动不切换快捷栏。
- [ ] 悬停物品变化后偏移归零。
- [ ] 其他模组追加的行可见。
- [ ] 滚动条贴图、颜色、宽度、间距可替换。
- [ ] 拖动滑块与滚轮偏移一致，松手后保持。
- [ ] `mode: auto|always|never` 行为正确。
- [ ] 禁用面板后恢复原版提示。

### 8.7 Boss 血条

- [ ] 单条/多条堆叠。
- [ ] 进度、标题、颜色正确。
- [ ] 背景/填充/覆盖层贴图可替换。
- [ ] `left_to_right` / `right_to_left` 填充方向正确。
- [ ] `tint_from_event` 开关行为正确。
- [ ] 未绑定血条保持原版。
- [ ] 血条移除后无残留。
- [ ] 禁用面板后恢复原版。

### 8.8 字体

- [ ] 中文、英文、数字、符号在缩放 1–4 下清晰。
- [ ] 回退链生效。
- [ ] 缺失字体不崩溃。
- [ ] 长文本换行与测量一致。

### 8.9 图片、URL 与 GIF

- [ ] 合法 https 图片显示，缓存命中不重复下载。
- [ ] 默认直连时服务端无图片上行；代理模式可切换。
- [ ] 内网、回环、非标准端口、超时 URL 被拒绝并记录。
- [ ] GIF 播放、暂停、循环、`speed` 正确。
- [ ] 超过帧数/单帧尺寸/总大小的 GIF 被拒绝。
- [ ] 界面隐藏或 `animations:false` 时动画暂停。
- [ ] 下载失败回退第一帧或缺失贴图。

### 8.9.1 输入框

- [ ] 中文/日文/韩文 IME 组合输入、提交、取消。
- [ ] 选区、Shift+方向键、Home/End、剪贴板。
- [ ] 背景、边框、字体、文字颜色、占位符、焦点/错误态可换皮。
- [ ] 清除按钮清空并触发 `change`。
- [ ] `sensitive: true` 掩码显示，日志无原文。
- [ ] NanoVG 后端下文字/光标/选区仍由原版绘制。

### 8.10 占位符刷新

- [ ] `%player_name%`、`${placeholder:...}` 正常显示。
- [ ] `static` 只在打开时解析。
- [ ] `interval` 按周期刷新，只推差异。
- [ ] `tick` 只在小规模元素上使用。
- [ ] `manual` 只在 `refresh` 动作后刷新。
- [ ] 异步白名单外仍同步；客户端不解析占位符。

## 9. 模组互操作

- [ ] REI / EMI / JEI：界面不被劫持，Tooltip 追加行可见。
- [ ] Sodium / Iris：NanoVG FBO 合成无异常；必要时回退原生。
- [ ] 物品栏整理/HUD 模组：无重复渲染。
- [ ] 其他 Tooltip 模组：无法接管时回退原版。
- [ ] 其他 Boss 血条模组：哨兵不匹配时保持原版。
- [ ] 其他也在 `setScreen` 注入的模组：界面仍可用。

## 10. 性能测试

- 200 元素合成页面，10 秒，p50/p95/p99。
- NanoVG 背景层/前景层耗时、FBO 合成耗时、每帧填充像素与显存带宽（480×270、960×540、1x/2x）。
- 100 元素、20 段文本的逐帧分配（JFR）。
- Tooltip 64 行滚动，测量布局与绘制。
- Boss 血条 3 条每帧开销。
- 遍历 128 项的布局与点击延迟。
- 1000 次打开/关闭内存回到基线 ±5%。
- 字体切换与首次加载耗时。
- GIF 精灵表轮播的每帧成本。
- 100 个 PAPI 变量按 `interval` 刷新的服务端 tick 成本。
- URL 下载与解码不阻塞主线程。

参考机器必须记录 CPU、GPU、内存、JVM 参数、Fabric API 版本。没有机器描述的数字不算结果。

## 11. 浸泡与故障注入

- 100 模拟会话 × 30 分钟：会话、贴图、分片、Boss 绑定、FBO、NanoVG image/font handle。
- 注入：丢分片、重复分片、乱序、畸形 JSON、未知面板、超长 Tooltip、重复 Boss 绑定、遍历爆炸、
  慢 PAPI 扩展、超大 GIF、失效 URL。
- 断言：不崩溃、无无界增长、计数器递增、面板要么恢复要么干净关闭。

## 12. Minecraft 更新回归

1. 重新验证 `10-risks-and-verification.md` 的未验证清单。
2. 按新映射重建 `NanoVgBackend`、`FboCompositor`、`NativeBackend` 和四个混入。
3. 重跑完整手动矩阵。
4. 重跑互操作。
5. 更新 README 兼容性表。

映射变化（例如 `ResourceLocation` → `Identifier`）属于编译期失败，成本最低；渲染签名变化是主要风险。

## 13. CI 概览

```
job build:
  - setup-java 21
  - ./gradlew build
job protocol:
  - 黄金向量 + jqwik 10 万次
job compose-repeat:
  - 组合、遍历、校验器测试
job docs:
  - Markdown 本地链接检查
  - 黄金文档与 schema 校验
  - DSL/协议/schema 字段一致性检查
job client-test（自托管 Windows）:
  - runClient -Dcloudcore.test.scenario=surfaces -Dcloudcore.test.renderer=nanovg
  - runClient -Dcloudcore.test.scenario=surfaces -Dcloudcore.test.renderer=native
```

夜间：完整模糊、30 分钟浸泡、客户端六面板场景。
